# Judul

Prediksi Risiko Diabetes dan Analisis Klaster Lokasi Gerai Kopi Menggunakan Algoritma Data Mining Berbasis Streamlit

---

# Deskripsi

Aplikasi ini dibangun menggunakan Python dan Streamlit untuk mengimplementasikan dua metode Data Mining.

## Modul 1

Prediksi Risiko Diabetes

Metode yang digunakan:

- K-Nearest Neighbor (KNN)
- Naive Bayes
- Decision Tree

Fitur:

- Prediksi pasien
- Perbandingan model
- Confusion Matrix
- Akurasi
- Precision
- Recall
- F1 Score

---

## Modul 2

Analisis Klaster Gerai Kopi

Metode:

K-Means Clustering

Fitur:

- Visualisasi Cluster
- Scatter Plot
- Prediksi Lokasi Baru
- Deteksi Zona Sepi

# Cara Menjalankan

Clone Repository

```bash
git clone https://github.com/username/DataMining-Diabetes-CoffeeShop.git
```

Masuk Folder

```bash
cd DataMining-Diabetes-CoffeeShop
```

Install Library

```bash
pip install -r requirements.txt
```

Jalankan

```bash
streamlit run app.py
```
